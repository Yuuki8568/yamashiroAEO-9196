この記事の内容
現在のディレクトリの名前、時刻と日付、Microsoft Windows のバージョン番号など、必要なテキストの表示など、Cmd.exe コマンド プロンプトを変更します。 このコマンドをパラメーターなしで使用すると、コマンド プロンプトが既定の設定にリセットされます。これは、現在のドライブ文字とディレクトリの後に、より大きい記号 (
>
) が続きます。
Syntax
prompt [<text>]
Parameters
Parameter
Description
<text>
コマンド プロンプトに含めるテキストと情報を指定します。
/?
コマンド プロンプトにヘルプを表示します。
Remarks
text
パラメーターの 1 つ以上の文字列の代わりに、または追加して含めることができる文字の組み合わせ:
Character
Description
$q
= (等号)
$$
$ (ドル記号)
$t
Current time
$d
Current date
$p
現在のドライブとパス
$v
Windows のバージョン番号
$n
Current drive
$g
> (より大きい記号)
$l
< (符号未満)
$b
|
(パイプ記号)
$_
ENTER-LINEFEED
$e
ANSI エスケープ コード (コード 27)
$h
Backspace (コマンド ラインに書き込まれた文字を削除するため)

プロンプト
コマンドは次の書式設定文字をサポートします。
Character
Description
$+
プッシュされた
ディレクトリスタックの深さに応じて、0 文字以上のプラス記号 (
+
) 文字 (プッシュされたレベルごとに 1 文字)。
$m
現在のドライブ文字に関連付けられているリモート名。現在のドライブがネットワーク ドライブでない場合は空の文字列。
テキストパラメータに
$p
文字を含めると、各コマンドを入力した後にディスクが読み取られます(現在のドライブとパスを決定します)。 これは、特にフロッピー ディスク ドライブの場合、余分な時間がかかる場合があります。
Examples
2 行のコマンド プロンプトを、現在の時刻と日付を最初の行に設定し、次の行のより大きい符号を設定するには、次のように入力します。
prompt $d$s$s$t$_$g
プロンプトは次のように変更されます。ここで、日付と時刻は最新です。
Fri 06/01/2007  13:53:28.91
コマンド プロンプトを矢印 (
-->
) として表示するように設定するには、次のように入力します。
prompt --$g
コマンド プロンプトを既定の設定 (現在のドライブとパスの後に大きい記号が続く) に手動で変更するには、次のように入力します。
prompt $p$g
