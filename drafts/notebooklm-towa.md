NotebookLMは、Googleが提供するAIのノート型ツールです。資料を読ませて質問できると聞いても、ChatGPTと何が違うのか、無料でどこまで使えるのか、会社の資料を入れてよいのかが分かりにくいまま、という声は少なくありません。加えて、2026年7月から名称がGemini Notebookに変わったため、検索すると2つの名前が混在しています。

結論から書きます。NotebookLMは、自分で追加した資料（ソース）を根拠に、質問への回答や要約、音声解説などを作るGoogleのAIリサーチツールです。名称はGemini Notebookに変わりましたが同じ製品で、Gmailアカウントがあれば無料で使い始められます。

## NotebookLMは何をする道具か

Googleの公式サイト（2026年10月2日に確認）のよくある質問では、2026年7月よりNotebookLMはGemini Notebookになり、これまでのNotebookLMはそのまま使え、既存のノートブックにもこれまでどおりアクセスできると説明されています。ヘルプセンターの見出しは「NotebookLM ヘルプ」のまま、本文はGemini Notebookという表記で、2つの名前が併記されている状態です。この記事では、検索されることの多いNotebookLMの名前で説明します。

仕組みは単純で、「ノートブック」という入れ物を作り、そこに資料を入れて、その資料について質問します。Googleの公式サイトでは、回答は常にユーザーが提供した情報に基づいて生成されると書かれています。Google Workspaceの管理者向けヘルプ（2026年10月2日に確認）では、ソースに基づいた情報がインラインの引用つきで示されると説明されています。

| よく聞かれる点 | 公式ページでの説明（2026年10月2日に確認） |
| --- | --- |
| 名前 | 2026年7月よりNotebookLMはGemini Notebookになる。既存のノートブックはそのまま使える |
| 回答の根拠 | ユーザーが提供した情報（ソース）に基づいて生成される |
| 根拠の示し方 | 回答にインラインで引用が明記される |
| 使える場所 | ウェブとモバイルのスタンドアロンのツールとして使える |
| 始め方 | 無料のStandardはGmailアカウントで登録できる |

## 入れられる資料と、作れるもの

Googleのヘルプ「ノートブックの新しいソースを追加または検索する」（2026年10月2日時点）では、次の種類の資料に対応しています。

| 資料の種類 | 主な対応形式と制限（2026年10月2日時点） |
| --- | --- |
| 文書 | PDF、Word（docx）、テキスト（txt）、マークダウン（md）、Googleドキュメント、ePub |
| 表・スライド | CSV、PowerPoint（pptx）、Googleスプレッドシート（10万トークンまで）、Googleスライド（最大100枚） |
| ウェブ・動画 | ウェブURL、公開されているYouTube動画のURL |
| 音声・画像 | MP3、WAVなどの音声ファイル、png、jpgなどの画像 |
| その他 | コピーして貼り付けたテキスト、Playブックスの対象書籍、Geminiチャット |
| 1ソースの上限 | 最大500,000語、ファイルサイズは200MBまで |

Googleドライブから取り込んだ資料は数分ごとに同期され、元の文書を直すとノートブック側にも反映されます。ただし、ドライブのファイルへのアクセス権を失ったり、ファイルが削除されたりすると、その資料はノートブックで使えなくなります。

資料を入れたあとに作れるものは、同じヘルプの上限表に並んでいます。業務に置き換えると次のようになります。

| 作れるもの | 業務での使い方の例 |
| --- | --- |
| チャットでの回答（引用つき） | 規程やマニュアルのどこに書いてあるかを確かめる |
| レポート | 複数の資料の要点を1つにまとめる |
| 音声解説・動画解説 | 新しく入った社員が移動中に資料の概要を聞く |
| フラッシュカード・クイズ | 手順書の理解度を確認する |
| マインドマップ・データテーブル | 資料同士の関係や、数値の一覧を整理する |
| スライド資料・インフォグラフィック | 社内説明用のたたき台を作る |

Google Workspaceの製品ページ（2026年10月2日に確認）でも、トレーニングマニュアルやポリシー文書を入れて新入社員が特定の手順について質問する、製品仕様を入れて営業の準備に使う、といった例が紹介されています。

## 無料版と有料版でどこまで違うか

無料のStandardでも主な機能は使えます。違いは使用量の上限です。Googleのヘルプ「Gemini Notebook をアップグレードする」（2026年10月2日時点、上限は変更される場合があると明記）の表から、業務で当たりやすい項目を抜き出しました。

| 項目 | Standard（無料） | Plus | Pro | Ultra（20TBプラン） |
| --- | --- | --- | --- | --- |
| ノートブック数 | 100件 | 200件 | 500件 | 500件 |
| 1ノートブックのソース数 | 50件 | 100件 | 300件 | 500件 |
| チャット | 1日50回 | 1日200回 | 1日500回 | 1日2,500回 |
| 音声解説 | 1日3件 | 1日6件 | 1日20件 | 1日100件 |
| レポート | 1日10件 | 1日20件 | 1日100件 | 1日500件 |
| 高度な共有 | なし | あり | あり | あり |

有料の上限は、Google AI Plus、Pro、Ultraのいずれかのプランに登録するか、対象となるGoogle Workspaceのプランを通じて使えるようになります。公式のプランページ（2026年10月2日に確認）では、Google AI Plus、Pro、Ultraは特定の地域でのみ利用できるとされているため、料金と提供状況は申し込み画面で確認してください。

会社で使う場合は、Workspaceの契約に含まれているかを先に確かめると無駄がありません。Workspaceの管理者向けヘルプ（2026年10月2日に確認）では、Business Starter、Business Standard、Business Plusなどのエディションにコアサービスとして付帯していると示されています。すでにWorkspaceを使っている会社なら、追加の契約なしで試せる可能性があります。

1人で日に数回質問する程度なら、無料の上限で足ります。チームで同じノートブックを共有して毎日使う、1つのテーマに50件を超える資料を入れたい、という段階で有料を検討するのが順序です。なお、ノートブックを共有しても共同編集者側のソース上限は変わらないと同じヘルプに書かれています。

## ChatGPTなどの対話AIとの違い

どちらも資料を読ませて質問できますが、作りの出発点が違います。NotebookLMは「入れた資料について調べる」ことを中心に作られています。ChatGPTは文章作成や相談など幅広い用途の対話AIで、OpenAIのヘルプ「ChatGPTのプロジェクト」（2026年10月2日に確認）によると、プロジェクトにPDFやスプレッドシート、文書、画像を追加すると、その内容を使ってより情報に基づいた回答を返せます。

| 観点 | NotebookLM（Gemini Notebook） | ChatGPT（プロジェクト機能を使う場合） |
| --- | --- | --- |
| 中心になる使い方 | 入れた資料について質問し、要約や学習用資料を作る | 相談、文章作成、調査など幅広い作業 |
| 資料のまとめ方 | ノートブックごとにソースを追加する | プロジェクトごとにファイルと指示をまとめる |
| 回答の根拠の示し方 | 回答にインラインで引用が付く（Googleの説明） | 追加した内容を使って回答する（OpenAIの説明） |
| 資料以外の出力 | 音声解説、動画解説、クイズ、マインドマップなど | 会話の中で文章や表を作る |

どちらが優れているかではなく、仕事の形で選ぶのが実務的です。決まった資料の束について、根拠の場所を確かめながら調べたいならNotebookLMが向いています。資料に限らない相談や、メールや企画書の下書きまで1つの場所で進めたいならChatGPTが合います。Googleの対話AIであるGeminiとChatGPTの比較は、[ChatGPTとGeminiは、業務で使うならどちらを選ぶべきですか](/posts/chatgpt-gemini-gyomu-hikaku)で扱っています。PDFの要約に限った使い分けは[PDFや長文資料をAIで要約するには、どのAIをどう使えばいいですか](/posts/pdf-yoyaku-ai-tsukaiwake)にまとめています。

## 会社の資料を入れる前に決めること

データの扱いは、使うアカウントで変わります。Googleのヘルプ（2026年10月2日に確認）の説明を整理すると次のとおりです。

| アカウントの種類 | トレーニングへの使用 | 人による確認 |
| --- | --- | --- |
| 個人のGoogleアカウント | フィードバックを提供しない限り使用されない | フィードバックを送ると、クエリ、アップロード、回答などやり取りの全容を確認する場合がある |
| Google Workspace（Education含む） | フィードバックを送っても使用されない | フィードバックを送っても人間のレビュアーは確認しない |

この表から、決めておくことは3つに絞れます。

| 決めること | 理由 |
| --- | --- |
| 会社のWorkspaceアカウントで使うこと | 個人アカウントでは、フィードバックを送ったときに人の確認が入る場合があるため |
| 入れてよい資料の範囲 | 個人情報や取引先の機密を含む資料を誰が判断するかを曖昧にしないため。ヘルプにも、権利がない文書をアップロードしないよう注意書きがある |
| 共有と削除のルール | 公式サイトのよくある質問で、現時点では削除したノートブックを復元するオプションはないとされているため |

Workspaceでは、管理者が組織内で利用できるユーザーを指定できます。社内ルールの全体像は[ChatGPTで情報漏洩は起きますか。会社として何を決めればよいですか](/posts/chatgpt-joho-roei-taisaku)と[生成AIの社内ガイドラインには何を書けばいいですか](/posts/seisei-ai-guideline-shanai-tsukurikata)で整理しています。内容はChatGPT向けの説明が中心ですが、決める項目はNotebookLMでも同じです。

## 使い方の最初の手順

Googleのヘルプに沿うと、最初の1冊は次の順で作れます。

1. ブラウザでNotebookLM（Gemini Notebook）を開き、Googleアカウントでログインする
2. 新しいノートブックを作成する
3. 左側の［ソースを追加］から、PDFやGoogleドライブのファイル、ウェブURLを追加する
4. チャット欄で、資料について具体的に質問する
5. 回答に付いた引用をクリックし、元の資料の該当箇所を確認する

質問の仕方にもコツがあります。同じヘルプでは、「このソースを要約して」ではなく、資料名を入れて求めている情報を具体的に聞くと、検索範囲を絞り込めると説明されています。複数の資料を入れている場合は、［ソース］パネルで使う資料を選んでから質問すると、答えの出どころがはっきりします。

## 業務での使いどころ

向いているのは、資料がすでにあって、そこから答えを探す時間がかかっている業務です。

| 業務 | 入れる資料の例 | 確認の仕方 |
| --- | --- | --- |
| 社内規程・手順の問い合わせ | 就業規則、経費精算の手順書 | 回答の引用から原文を開いて確かめる |
| 新しく入った社員への説明 | 業務マニュアル、よくある質問の一覧 | 音声解説やクイズで理解度を見る |
| 営業・提案の準備 | 製品仕様書、過去の提案資料 | 数値は必ず元の資料で確認する |
| 会議の振り返り | 議事録、配布資料 | 決定事項の抜けがないかを担当者が見る |

一方で、毎回同じ手順で処理する作業や、社内システムへの入力まで進めたい作業は、資料を調べる道具の範囲を超えます。そうした作業は、[AIエージェントとは何ですか。生成AIやChatGPTとの違いをわかりやすく](/posts/ai-agent-towa)で説明している仕組みや、従来型の自動化の領域です。
