# 経理の仕事はAIでどこまで任せられますか。経理の仕事はなくなりますか

答え: 読み取り、仕訳の候補出し、明細の突き合わせ、社内ルールとの照合といった繰り返しの処理はAIに任せられる部分が広がっています。一方で、勘定科目の最終判断、税務上の処理の決定、税務署へ出す書類の作成は人と税理士の領域です。経理の仕事がなくなるというより、入力中心から確認と判断中心に寄っていくと捉えるのが実態に近いです。

対象読者: 経理担当が1人から数人で、月末月初に伝票入力と領収書の処理に追われている中小企業の経営者、経理・管理部門の責任者、経理を兼務している総務担当の方

## 任せられる作業と、人に残る作業の線引き

経理の仕事は一枚のかたまりではありません。作業の種類ごとに、任せられる度合いがはっきり違います。

| 作業 | AIに任せられる度合い | 人が必ず関わるところ |
| --- | --- | --- |
| 領収書・請求書の読み取り（日付・金額・取引先） | 高い | 読み取り結果の確認、読めなかった書類の処理 |
| 仕訳の候補出し（過去の仕訳をもとに科目を提案） | 中くらい | 科目の最終決定、前例のない取引の判断 |
| 明細の突き合わせ（カード明細・入出金と申請内容） | 高い | 不一致が出た件の原因確認 |
| 経費規程との照合（申請が社内ルールの範囲内か） | 中くらい | 例外を認めるかの判断 |
| 月次の数字のチェック（前月比の差が大きい項目を拾う） | 中くらい | 差の理由の説明、経営への報告 |
| 税務上の処理の決定、申告書の作成 | 任せられない | 税理士の業務（税理士法第2条・第52条） |

線引きの基準は単純です。過去の例をもとに答えを出せる作業は任せられ、根拠を示して責任を負う必要がある作業は人に残ります。

## 数字で見ると、経理へのAI導入はどの位置にあるか

期待値を合わせるために、全体の状況を確認します。

総務省の令和8年版情報通信白書（図表Ⅰ-2-1-7、2026年9月18日に確認）では、業務類型ごとの生成AIの活用状況が示されています。経理・財務については、「業務プロセスがAI中心に変更されている」が9.3％、「部署内の特定業務で活用している」が19.5％、「従業員が個人作業の効率化で活用している」が15.9％で、合計すると4割台半ばです。

比較のために並べると、「議事録・メール作成補助」は同じ3項目の合計で約7割、「営業・販売」が約6割、「社内ヘルプデスク」が約5割となっています。

導入効果の実感については、活用していると回答した企業に限った集計として、「議事録・メール作成補助」が72.3％で最も高く、経理・財務は29.7％です。

ここから読めることは2つあります。経理・財務は、手をつけている企業が一定数ある領域である。ただし、文章づくりの補助ほど手応えが出やすい領域ではない。

理由は、経理の作業が社内の他の条件とつながっているからです。文章の草案づくりは1人で完結しますが、経費精算は申請する社員の入力、承認する上司の判断、規程の中身に左右されます。経理担当の手元だけを速くしても、手前の申請が雑なままなら確認の手間は残ります。

## 「経理の仕事はなくなるのか」への答え

検索でよく並ぶ問いですが、業務の中身に照らすと、なくなるという表現は実態と合いません。

まず、法令上ずっと人に残る領域があります。税理士法第2条は、税務代理、税務書類の作成、税務相談の3つを税理士の業務と定めており、同法第52条は税理士または税理士法人でない者がこれを行うことを禁じています（2026年9月18日にe-Gov法令検索で条文を確認）。AIが計算を助けたとしても、税務署に出す書類を確定させる責任の所在は変わりません。

次に、社内での責任の話です。帳簿の数字は、金融機関や税務調査の場で説明を求められます。そのときに「AIがそう出したから」では通りません。説明できる人が最後に確認する構造は残ります。

変化として現実的なのは、担当者の時間の使い方が移ることです。入力と転記に費やしていた時間が減り、確認、例外処理、数字の意味を説明する仕事の比重が増えます。求められる力も、速く正確に打つことから、出てきた結果の誤りに気づくことへ寄っていきます。

## 進め方の順番

いきなり会計システムを入れ替えるのではなく、対象を1つに絞って始める形が手戻りが少なくなります。

1. 対象を1つ選ぶ。月間の件数が多く、判断が少ない作業が向きます。領収書の読み取り、カード明細の突き合わせなどです。
2. 現状を測る。月間の件数と、1件あたりの所要時間を2週間だけ記録します。これがないと、あとで効果を判断できません。
3. 下書きと承認に分ける。AIが候補を出し、人が承認する手順に組み替えます。承認の記録が残る形にしてください。
4. 例外の受け皿を決める。読み取れなかった書類、前例のない取引を誰がどう処理するかを先に決めます。ここが決まっていないと、例外が机の上に積み上がります。

3と4を省いた導入が、後から手間を増やす典型です。候補を出すところまでは動くのに、誤りを見つける手順と例外の行き先がないため、結局すべてを目視で見直すことになります。

## 専用サービスと汎用AIの使い分け

| 判断軸 | 経理向けの専用サービスが向く | 汎用AIが向く |
| --- | --- | --- |
| 扱うもの | 会計データ・伝票そのもの | 説明文、手順の検討、集計の組み立て |
| 件数 | 月に数百件以上ある | 月に数十件程度 |
| 求める形 | 申請から承認までの流れを電子化したい | 担当者の手元の作業を速くしたい |
| 保存要件 | 電子帳簿保存法への対応を製品側に任せたい | 保存は既存の仕組みのまま |
| 導入の重さ | 社内の運用変更を伴う | 明日から試せる |
| 費用の形 | 月額（製品と規模により幅が大きい） | 1人あたりの月額 |

多くの中小企業では、右の列で担当者の下調べや説明文づくりを速くしながら、どの作業に時間が取られているかを把握し、そのうえで件数の多い業務に専用サービスを検討する順番が現実的です。

なお、経理向けの専用サービスは製品ごとに価格体系と対応範囲が大きく異なります。料金は変更されることがあるため、各製品の公式サイトで最新の内容をご確認ください。

## 法令面で先に確認しておくこと

経理の業務は、他の部門より法令との接点が多いため、AIを挟むときに確認しておく点があります。

- 電子取引データの保存: 電子帳簿保存法では、取引情報を含む電子データをやり取りした場合の保存義務と保存方法が定められています（国税庁の電子帳簿等保存制度特設サイト、2026年9月18日に確認）。AIに読み取らせたあと、原本のデータをどこにどう保存するかを決めてください。
- 税理士の業務との境界: 税務代理、税務書類の作成、税務相談は税理士の業務です（税理士法第2条・第52条）。仕訳の考え方に迷う場合は、顧問の税理士に確認する経路を残してください。
- 入力してよいデータの範囲: 請求書には取引先名、金額、口座情報が含まれます。どのサービスに、どの範囲まで入れてよいかを社内で明文化してください。

3つ目については、使うサービス側の設定も確認が必要です。OpenAIのエンタープライズプライバシーのページ（2026年9月18日に確認）では、ChatGPT Business・Enterprise・Eduなどで既定ではユーザーのデータをモデルの学習に使用しないこと、ChatGPT Businessでは管理者が保持期間を設定でき、削除した会話は法令上の保持義務がない限り原則30日以内に削除されることが案内されています。利用規約とプランの内容は変更されることがあるため、契約前に各社の公式ページでご確認ください。

## 1か月後に見る指標

- 対象にした作業の1件あたり所要時間（着手前の記録と比べます）
- 手直しが不要だった件数の比率（低い場合、渡している情報が足りていない可能性があります）
- 例外として人に回った件数とその内容（次に整えるルールの候補になります）
- 締めの作業が前倒しできたか（月初の何営業日目に終わったか）
- 誤った科目が帳簿に入った件数（増えているなら、承認の手順を見直してください）

数字が動かないとき、原因は多くの場合ツールの選定ではなく、手前の申請や書類の出し方が揃っていないことにあります。申請時の入力項目や添付ルールを先に整えると、同じツールでも結果が変わります。

## よくある質問

### AIで経理の仕事はなくなりますか
仕事がまるごと消えるという見方は、経理業務の中身と合いません。経理の作業は、入力・転記・突き合わせといった手を動かす部分と、科目の判断・例外処理・締めの整合性を見る部分に分かれます。AIが得意なのは前者で、後者は根拠を持って説明できる人が必要です。さらに、税務署に提出する申告書の作成や、課税標準等の計算に関する相談は税理士法第2条で税理士の業務と定められており、第52条により税理士でない者は行えません（2026年9月18日にe-Gov法令検索で条文を確認）。つまり、経理の中でも法令上ずっと人に残る領域があります。変化として現実的なのは、担当者の時間配分が入力から確認・判断へ移ることです。

### 経理に向いているAIはどれですか
用途を2つに分けて考えると迷いません。1つは、経費精算や請求書処理といった決まった業務そのものを担う専用のクラウドサービスです。総務省の令和8年版情報通信白書（2026年9月18日に確認）は、経理・財務領域の事例としてラクスの経費精算システムを挙げており、同社の発表（2025年12月1日、2026年9月18日に確認）では、蓄積された領収書データ・事前申請伝票・クレジットカード明細・過去の申請履歴をAIが横断的に解析して申請伝票を自動作成し、社内規定に沿っているかを規定チェック機能で確認する機能がβ版として提供開始されたと案内されています。もう1つは、汎用のAI（ChatGPT、Claude、Geminiなど）で、仕訳の考え方の下調べ、社内向け説明文の作成、Excelの集計手順を組み立てる用途に向きます。会計データそのものを扱うなら前者、担当者の手元の作業を速くしたいなら後者が出発点です。

### AIを経理業務に活用する方法を具体的に教えてください
着手しやすい順に4つあります。1つ目は領収書や請求書の読み取りで、紙やPDFから日付・金額・取引先を取り出す作業です。2つ目は仕訳の候補出しで、過去の仕訳を基準に科目を提案させ、人が承認する形にします。3つ目は突き合わせで、クレジットカード明細や入出金データと申請内容の一致を確認します。4つ目は社内ルールとの照合で、申請が経費規程の範囲内かを確認する作業です。いずれも共通しているのは、AIが下書きを作り、人が承認する形にすることです。承認の手順を省くと、誤った科目のまま帳簿に入り、後の修正のほうが手間になります。

### 領収書や請求書のデータをAIに読み込ませても問題ありませんか
2つの観点で確認が必要です。1つは、使うサービスがそのデータを学習に使わない設定になっているかです。OpenAIのエンタープライズプライバシーのページ（2026年9月18日に確認）では、ChatGPT Business・Enterprise・Eduなどで既定ではユーザーのデータをモデルの学習に使用しないこと、ChatGPT Businessではワークスペース管理者が保持期間を設定でき、削除した会話は法令上の保持義務がない限り原則30日以内に削除されることが案内されています。もう1つは保存義務のほうです。電子帳簿保存法では、取引情報を含む電子データをやり取りした場合の保存義務と保存方法が定められています（国税庁の電子帳簿等保存制度特設サイト、2026年9月18日に確認）。AIに読み取らせたあとの原本の扱いを決めずに進めると、保存要件を満たさない状態になりかねません。取引先名や口座情報を含む書類を扱うため、社内で入力してよいデータの範囲を先に決めてください。

### 経理にAIを入れると、どのくらい効果が出ますか
件数と現状の手順によって幅が大きく、一律の削減率は示せません。目安として、総務省の令和8年版情報通信白書（図表Ⅰ-2-1-7、2026年9月18日に確認）では、経理・財務での生成AIの活用状況について「業務プロセスがAI中心に変更されている」9.3％、「部署内の特定業務で活用している」19.5％、「従業員が個人作業の効率化で活用している」15.9％と報告されており、合計で4割台半ばです。活用していると回答した企業に限った集計では、導入効果を実感する業務として経理・財務を挙げた割合は29.7％で、最も高い「議事録・メール作成補助」の72.3％とは差があります。手をつけている企業は一定数ある一方、文章づくりの補助ほど手応えが出やすい領域ではない、という読み方が実態に近いです。自社の効果は、対象にする作業の月間件数と1件あたりの所要時間を先に測ってから判断してください。
