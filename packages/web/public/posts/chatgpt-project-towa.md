# ChatGPTのプロジェクトとは何ですか。無料での作り方と、メモリ・共有の注意点は？

答え: ChatGPTのプロジェクトは、関連するチャット・資料・指示をまとめ、継続する作業で使う機能です。無料プランでも利用できますが、ファイル数などに上限があります。業務では資料の版、メモリの参照範囲、共有相手を確認し、回答の事実は元資料と照合します。

## プロジェクトとは。資料と会話を同じ作業単位へまとめる機能

ChatGPTのプロジェクトは、関連する会話、参考資料、指示をまとめる場所です。2026年10月15日時点の[OpenAI公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)は、継続する執筆・調査・計画などに、まとめた文脈を使えると説明しています。

たとえば毎週の報告書の下書きなら、報告の形式を指示として置き、参照を許可された資料を追加し、週ごとにチャットを分ける運用が考えられます。これは当事務所の説明用の運用例で、実在する支援先の成果や削減時間を示すものではありません。

単に会話を整理することと、業務システムへ登録・送信することは別です。資料の内容を使った回答でも、数字、日付、担当者、決定事項は元資料と照合します。業務全体の始め方は[ChatGPTを業務で活用するには](/posts/chatgpt-gyomu-katsuyo-tejun)をご覧ください。

## 普通のチャットとプロジェクトの違い

次の表は作業単位の整理です。機能の根拠は2026年10月15日確認の[公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)で、使い分けは当事務所の提案です。性能の優劣を測定した比較ではありません。

| 観点 | 普通のチャット | プロジェクト |
| --- | --- | --- |
| 作業のまとめ方 | その会話に条件や材料を渡す | 関連する会話・資料・指示をまとめる |
| 指示 | 会話で今回の条件を伝える | プロジェクト内に共通の指示を設定する |
| 使い方の例 | 一度だけの文章案や相談 | 同じテーマの継続した下書き・検討 |
| 点検するもの | 今回の入力と回答 | 今回の入力に加え、保存資料の版・過去の会話・メモリ・共有 |

公式ヘルプでは、プロジェクトの指示はそのプロジェクト内だけに適用され、グローバルのカスタム指示より優先するとされています。「全チャットに設定したから同じ動きになる」と考えず、ここに設定した内容も確認してください。

## 無料か。プロジェクト数とファイル上限は別

2026年10月15日時点の[公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)は、Freeを含むプランでの利用・共有を案内し、対象プランのプロジェクト利用には追加料金が不要と説明しています。モデルやツールにかかる使用量・クレジット等は通常のチャットと同様に適用されるため、無制限に処理できるという意味ではありません。

| 項目 | 2026年10月15日時点の公式案内 |
| --- | --- |
| 作成するプロジェクト数 | 無制限 |
| Freeのファイル数 | 1プロジェクトにつき5件 |
| Go・Plusのファイル数 | 1プロジェクトにつき25件 |
| Edu・Pro・Business・Enterpriseのファイル数 | 1プロジェクトにつき40件 |
| 同時アップロード | 10件まで |

出典：[Projects in ChatGPT「Plans and limits」](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)。ファイルの件数は、1件のサイズやチャットの利用量と同じ制限ではありません。必要な機能が会社の契約・管理者設定で使えるかも確認します。有料プランの価格はこの記事では比較しません。

## 作り方。最初は1業務・架空の資料から

以下の操作は2026年10月15日確認の[公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)に基づき、業務向けの点検を加えたものです。画面名は環境で変わるため表示も確認します。

1. 会社が認めるアカウントでChatGPTへログインする。
2. サイドバーの「New project」から名前、アイコン、色を選ぶ。
3. プロジェクト設定で、この作業に共通する指示を追加する。
4. 共有してよい架空の資料やテキストを追加し、内容と版を確認する。
5. メモリの参照範囲を確認したうえで、プロジェクト内でチャットを始める。
6. 元資料と回答を照合し、採用する文書は承認された保存先で管理する。

### 週報の下書き用の指示例

以下は当事務所が説明用に作成した例です。公式テンプレートや実測結果ではありません。

```text
用途: 人が確認する週報の下書き。
今回のメモを「実施済み・未完了・要確認」に分ける。
メモにない担当者、期限、進捗率は作らない。
提案を決定事項として扱わない。
資料の版が不明な場合は確認事項へ回す。
出力: 箇条書きの下書きと、人が照合する項目。
```

試す入力は「架空のメモ：手順書の見直しを提案。担当と期限は未定。次回検討」のようにします。見直しが完了済みになっていないか、架空の期限が追加されていないかを確認します。禁止条件を書いても守られる保証はないため、人の点検を残します。

指示の組み立ては[プロンプトとは何ですか](/posts/prompt-towa)にまとめています。古い会話を移す場合、公式ヘルプでは対象チャットをドラッグするか「Move to project」を選び、移動後はプロジェクトの指示と資料の文脈を引き継ぐとしています。すべてのチャットが移動できるわけではありません。不要な過去の会話までまとめて入れないでください。

## メモリは、資料の正確さやアクセス制限とは別

2026年10月15日時点の[公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)は、Default memoryとProject-only memoryを案内しています。確認日時点では作成時の選択に加え、既存プロジェクトの設定からも変更でき、反映に数時間かかる場合があります。過去の手順にある「作成時しか選べない」を現行条件として扱わないでください。

| 設定 | 参照範囲の説明 | 業務での注意 |
| --- | --- | --- |
| Project-only memory | 以前の保存メモリやプロジェクト外の会話を参照せず、同じプロジェクト内の会話を参照できる | 案件を分けても、同じ場所に混ぜた資料・会話は点検する |
| Default memory | 保存メモリや同じプロジェクトの会話を使い、外部会話の参照はプラン等で異なる | 別テーマの会話まで使えるかを確認する |
| 共有プロジェクト | 自動的にProject-onlyになり、Defaultへ戻せない | 個人の外部メモリではなく、共有した材料の範囲を確認する |

同日の公式案内では、Enterprise・EduのDefaultはプロジェクト外の会話を参照しない一方、Businessを含む他のプランでは、設定条件によりプロジェクト外の会話を参照できるとしています。メモリの利用には個人・ワークスペースの設定条件もあります。Project-onlyではChatGPT Workを使えないとの制限も掲載されています。

参照を限定しても、誤読や事実の追加を防ぐ保証、モデル学習の停止、社内限定アクセスにはなりません。これらは別々に確認します。

## 共有すると、会話だけでなく資料と指示も見える

2026年10月15日確認の[公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)では、共有メンバーはプロジェクトのチャット、ファイル、メンバー一覧を閲覧でき、全員がファイルをダウンロードできます。権限名のchatを「完成した回答しか見えない権限」と解釈しないでください。

| 共有時の選択 | できること・条件 | 先に確認する点 |
| --- | --- | --- |
| chat権限 | チャット、ファイル、指示を参照・利用 | 見せてよい元資料だけか |
| edit権限 | 指示・ファイルを変更し、他の人を招待できる | 誰が変更を確認するか |
| Only those invited | 招待した人に限定する設定 | 招待先、権限、組織の共有ルール |
| Anyone with a link | リンクを持つログイン済みChatGPTユーザーが参加できる | リンクの転送による参加を認めるか |

社内だけにリンクを送ることと、招待限定を設定することは別です。管理されたワークスペースでは組織の制限が適用されます。個人向けのリンク参加条件を会社の契約へ一律に当てはめません。

単独チャットの共有とプロジェクト全体の共有も異なります。公式案内では、私的なプロジェクトから単独チャットを共有しても他の会話・資料・指示へのアクセスは付与されず、共有プロジェクト内のチャットは受け手も参加するまで閲覧できないとされています。共有前に、渡す対象が会話か作業全体かを確認してください。

プロジェクト削除は取り消せず、会話・指示・そのプロジェクトだけに保存したファイルが削除対象です。Libraryに別保存したファイルは別扱いとされています。保存元の確認なしに削除を運用の整理方法にしないでください。

## 学習利用をオフにしても、保存や共有は別に残る

2026年10月15日時点の[Data controls公式ヘルプ](https://help.openai.com/en/articles/7730893-data-controls-in-chatgpt)は、Improve the model for everyoneをオフにすると、その後の新しい会話はモデル学習に使われないと説明しています。ただし会話は履歴やプロジェクトに残り、削除されるわけではありません。フィードバックを送った場合は、関連する会話全体が学習に使われる可能性があります。

同日の[Projects公式ヘルプ](https://help.openai.com/en/articles/10169521-projects-in-chatgpt)では、個人向けの共有プロジェクトは所有者と全投稿者が学習設定をオンにしている場合にモデル改善へ使われうるとされています。Business・Enterprise・Edu等では初期設定でモデル学習に使わないと説明されていますが、組織の保持期間・アクセス設定なども適用されます。

「メモリを切る」「学習を切る」「共有しない」は同じ操作ではありません。顧客情報や認証情報を入れてよいかは、会社の承認、利用目的、契約、保存と共有まで確認してください。社内の線引きは[生成AIの社内ガイドライン](/posts/seisei-ai-guideline-shanai-tsukurikata)で扱っています。

## よくある質問

### ChatGPTのプロジェクトとは何ですか？
関連するチャット、ファイル、プロジェクト内の指示をまとめる機能です。2026年10月15日時点のOpenAI公式ヘルプでは、継続する執筆・調査・計画などの文脈として使えると説明しています。資料を入れただけで回答の正確さや承認済みの状態が保証されるわけではありません。

### ChatGPTのプロジェクトは無料ですか。有料ですか？
2026年10月15日時点の公式ヘルプではFreeも対象で、対象プランのプロジェクト利用に追加料金は不要とされています。ただしモデルやツールの使用量・クレジット等は通常のチャットと同様に適用されます。無料プランの1プロジェクトあたりのファイル上限は5件です。出典：https://help.openai.com/en/articles/10169521-projects-in-chatgpt

### ChatGPTのプロジェクトはいくつまで作れますか？
2026年10月15日時点の公式ヘルプでは、作成するプロジェクト数は無制限です。ファイル上限は別で、1プロジェクトにつきFreeは5件、Go・Plusは25件、Edu・Pro・Business・Enterpriseは40件。同時アップロードは10件までです。チャットの利用量は契約に応じた上限があります。

### プロジェクトに入れてはいけない情報は何ですか？
会社が外部サービスへの入力を認めていない個人情報、顧客資料、秘密情報、認証情報などは入れないでください。2026年10月15日確認の公式案内では、学習利用の設定、メモリ、共有は別の確認事項です。学習をオフにしても入力自体の許可や共有先の確認は省けません。架空の材料から試します。

### 共有すると、メンバーはファイルや指示も見られますか？
はい。2026年10月15日時点の公式ヘルプではchat権限でもチャット・ファイル・指示を参照でき、全メンバーが追加ファイルを閲覧・ダウンロードできます。edit権限では指示やファイルの変更、招待も可能です。招待限定とリンクを知る人の参加を分け、共有前に見せてよい資料か確認します。
